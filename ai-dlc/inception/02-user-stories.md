## US-01 단어 카드 학습 (스와이프 분류)
- 우선순위: P0 · 연관 요구사항: FR-01, FR-03, FR-04 · 후보 Unit: UoW-03-learn-deck (의존: UoW-01, UoW-02)
- **학습자**로서 단어 카드를 보고 좌/우로 스와이프해 "알고 있어요/학습할게요"로 분류하고 싶다, 그래서 아는 것은 넘기고 모르는 것에 집중한다.
- 수용 기준:
  - Given 덱에 카드가 있을 때, When 우로 스와이프, Then "학습할게요"로 분류되고 다음 카드로 전환된다.
  - Given 방금 분류했을 때, When undo, Then 직전 카드/상태가 복원된다.
  - Given 덱을 모두 소진했을 때, Then 빈/완료 상태가 표시된다.

## US-02 발음 듣기 (무료 TTS)
- 우선순위: P0 · 연관 요구사항: FR-02 · 후보 Unit: UoW-04-tts (의존: UoW-00)
- **학습자**로서 단어와 예문의 프랑스어 발음을 버튼으로 듣고 싶다, 그래서 키나 인터넷 없이도 정확한 소리로 익힌다.
- 수용: Given 카드, When 발음 버튼, Then `fr-FR`로 해당 텍스트가 재생된다(설정 속도 반영).

## US-03 간격반복 복습
- 우선순위: P0 · FR-05, FR-06, FR-07 · UoW-05-srs / UoW-06-review-stats (의존: UoW-02 / UoW-03,05)
- **학습자**로서 "학습할게요" 단어가 적절한 간격으로 다시 나오길 원한다, 그래서 장기 기억에 남긴다.
- 수용: Given 분류 이력, When 시간 경과, Then 마감(due) 카드만 복습 큐에 뜨고, 앱 재시작 후에도 진행이 복원된다.

## US-04 정적 폴백 (키 없이 동작)
- 우선순위: P0 · FR-11, FR-14 · UoW-02-content-layer (의존: UoW-00)
- **사용자**로서 API 키 없이도 앱이 완전히 동작하길 원한다, 그래서 부담 없이 바로 학습한다.
- 수용: Given 키 미입력, Then 번들 A1 데이터셋으로 카드가 채워지고 모든 학습 기능이 동작한다.

## US-05 통계·연속 학습
- 우선순위: P1 · FR-09 · UoW-06-review-stats (의존: UoW-03, UoW-05)
- **학습자**로서 streak·학습 단어 수·레벨 진척을 보고 싶다. 수용: 통계 값이 실제 학습 상태와 일치.

## US-06 북마크
- 우선순위: P1 · FR-08 · UoW-07-bookmarks (의존: UoW-01, UoW-05)
- **학습자**로서 단어를 북마크해 따로 모아 복습하고 싶다. 수용: 토글이 영속되고 목록은 북마크만, 거기서 복습 진입.

## US-07 설정 & API 키
- 우선순위: P1 · FR-10, FR-11 · UoW-08-settings-keys (의존: UoW-00, UoW-01)
- **사용자**로서 TTS 속도·레벨을 바꾸고 API 키를 안전하게 입력/삭제하고 싶다.
- 수용: 키는 secure-store에만(평문 무노출), 입력 시 AI 경로, 삭제 시 즉시 정적 폴백. "데이터 초기화"는 학습 데이터만(키는 별도).

## US-08 AI 콘텐츠 강화
- 우선순위: P2 · FR-11 · UoW-09-ai-provider (의존: UoW-02, UoW-08)
- **사용자**로서 키가 있으면 더 풍부한 예문/번역을 받고 싶다, 단 실패 시 정적으로 폴백되길 원한다.
- 수용: 키+성공 시 AI 결과 캐시, 키 없음/에러 시 자동 Static 폴백(가짜 클라이언트로 검증).

## US-09 단어 이미지
- 우선순위: P2 · FR-13 · UoW-10-images (의존: UoW-02, UoW-08)
- **학습자**로서 단어에 맞는 이미지로 기억을 돕고 싶다. 수용: 키 없으면 카테고리 플레이스홀더, 이미지 키 시 imagePrompt로 생성·캐시, 실패 시 폴백.

## US-10 온보딩 & 폴리시 (햅틱·접근성)
- 우선순위: P1 · FR-12 · 후보 Unit: UoW-11-onboarding-polish (의존: UoW-01, UoW-03, UoW-06, UoW-08)
- **첫 사용자**로서 온보딩에서 레벨을 고르고 바로 학습을 시작하고 싶다. 수용: 온보딩→레벨로 시작, 스와이프 확정 시 햅틱, 폰트 스케일·대비(WCAG AA)·스와이프 접근성 라벨 동작.
