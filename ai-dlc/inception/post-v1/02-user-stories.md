## US-P1 문장으로 굳다 (i+1 문장 학습)

- 우선순위: P0 · 연관 요구사항: FR-P1 · 후보 Unit: UoW-13-sentence-layer
- **학습자**로서 *이미 익힌 단어로 이루어진 짧은 프랑스어 문장*을 보고 싶다, 그래서 *낱말이 실제 문장 안에서 어떻게 쓰이는지 부담 없이 익힌다*.

수용 기준:
- Given `box≥임계로 익힌 단어가 충분한 상태`, When `문장 층에 진입`, Then `미지 단어 1~2개만 포함한 청크 중심 문장이 노출되고, 새 단어/청크가 시각적으로 강조된다`.
- Given `익힌 단어가 임계 미만(콜드 스타트)`, When `문장 층에 진입`, Then `"단어를 더 익히면 문장이 열려요" 빈 상태가 차분히 표시된다(에러 아님)`.
- Given `BYOK 키 없음`, When `문장을 더 보려 함`, Then `정적 큐레이션 문장으로 동작(폴백)하고 첫 레슨은 무료로 열린다`.

## US-P2 패턴이 보이다 (문법 cloze)

- 우선순위: P1 · 연관 요구사항: FR-P3 · 후보 Unit: UoW-15-grammar-cloze
- **학습자**로서 *문장에서 반복되던 규칙(성·관사·활용·엘리지옹)을 빈칸으로 직접 채워보고* 싶다, 그래서 *읽고 넘기는 게 아니라 능동 회상으로 문법을 굳힌다*.

수용 기준:
- Given `문장 층에서 패턴이 충분히 노출됨`, When `해당 grammarPattern의 cloze 과제 진입`, Then `문장의 타깃 토큰이 빈칸으로 마스킹되고 입력/선택으로 답한다`.
- Given `타깃 토큰이 문장에 여러 번 등장(예: le)`, When `cloze 생성`, Then `토큰 경계로 정확히 한 위치만 마스킹된다(오마스킹 없음)`.
- Given `CEFR 레벨/box 미충족`, When `cloze 진입 시도`, Then `soft-gate가 "아직 일러요" 추천만 하고 강제 차단하지 않는다`.

## US-P3 직접 만들어보다 (가이드 산출 + 피드백)

- 우선순위: P1 · 연관 요구사항: FR-P4 · 후보 Unit: UoW-16-apply-production
- **학습자**로서 *익힌 단어·패턴으로 빈칸을 채우거나 문장을 재배열·번역해보고 즉시 교정*받고 싶다, 그래서 *수용에서 산출로 넘어가 "알지만 못 쓰는" 정체를 깬다*.

수용 기준:
- Given `산출 과제(빈칸/재배열/번역)`, When `답을 제출`, Then `정오답과 해설이 표시된다(BYOK 키 있으면 AI 교정, 없으면 정적 정답+해설 폴백)`.
- Given `산출 과제 정오답 결과`, When `결과 반영`, Then `classifyCard(스와이프 SRS 신호)에 절대 섞이지 않고, 별도 진척 카운터에만 기록된다`.

## US-P4 내 문장으로 쓰다 (자유 산출 → 설경 편입)

- 우선순위: P2 · 연관 요구사항: FR-P5 · 후보 Unit: UoW-17-usage-output
- **학습자**로서 *주제(예: 카페에서 주문하기)에 맞춰 짧게 직접 써보고 그 결과가 내 설경에 남게* 하고 싶다, 그래서 *익힌 것을 실제로 활용하고 성취가 쌓이는 걸 본다*.

수용 기준:
- Given `주제 프롬프트`, When `자유 작문을 저장`, Then `산출물이 로컬에 보존되고(자가평가 가능) 설경에 한 폭으로 편입된다`.
- Given `BYOK 키 있음`, When `작문 제출`, Then `AI 피드백이 표시된다(키 없으면 자가평가만)`.

## US-P5 설경 — 굳기 격자 (비강압 진척)

- 우선순위: P1 · 연관 요구사항: FR-P2, FR-P6 · 후보 Unit: UoW-14-soft-gate-engine, UoW-18-snowscape-viz
- **학습자**로서 *내가 익힌 것이 눈송이→결정→격자→설경으로 쌓이는 걸 보고* 싶다, 그래서 *점수·스트릭 압박 없이 "나만의 풍경"이 자라는 내적 동기로 지속한다*.

수용 기준:
- Given `여러 층에 진척이 있음`, When `설경 화면을 연다`, Then `층별 굳기(Leitner box 기반)와 "산출 가능 청크/문장 수"가 시각화되고, 잠긴 상위 층은 추천으로만 표시된다`.
- Given `복습을 며칠 미룸`, When `다시 진입`, Then `구조가 무너지지 않고 일부가 "흐려졌다 다시 선명"해질 뿐, 죄책감 카피·스트릭 끊김 경고가 없다`.
- Given `이미 굳은(상위 box) 항목`, When `시간 경과`, Then `영구 보존되어 사라지지 않는다`.

## US-P6 평생 해금 (depth-paywall · 구독 없음)

- 우선순위: P1 · 연관 요구사항: FR-P7 · 후보 Unit: UoW-19-monetization-iap
- **학습자**로서 *깊은 층 전체를 구독 없이 한 번 결제로 평생 열고* 싶다, 그래서 *디지털 월세·해지 불안 없이 내 학습 자산을 소유한다*.

수용 기준:
- Given `무료 사용자`, When `깊은 층 진입`, Then `단어 층·SRS·TTS·통계·오프라인은 영원히 무료로 동작하고(인질 없음), 문장 층 첫 레슨은 무료 미리보기로 열린다`.
- Given `평생 해금 구매 완료`, When `깊은 층 진입`, Then `문장·문법·응용·활용·설경 심화가 영구 열린다(청구 없음)`.
- Given `기기 교체/재설치`, When `복원(Restore Purchases)`, Then `계정 없이 StoreKit 영수증으로 권한이 복원된다`.
- Given `결제 화면`, When `진입`, Then `"구독 없음·자동갱신 없음·광고 없음·데이터 안 팜" 정직 페이지와 무료/유료 경계가 투명하게 표시된다`.
